# Get help

> Ask a person, and read what other people already asked

Leaftext is made by one person, so there is no support desk. Questions are asked and answered in public, so the answer you get is the one the next person finds.

## Where to ask

Ask on **[Get help](https://github.com/ryanallen/leaftext/discussions/categories/get-help)**, the questions page of the project's Discussions. Anyone can read and search it, and posting needs a free GitHub account.

In the app, press **Get help** on the last line of the start screen. It opens that page in your browser, and nothing is sent from the app.

## What to say

| Say | Where to find it |
| --- | --- |
| The version you are running | The last line of the start screen, beside **Get help** |
| Your platform | macOS or Windows, and which version |
| The kind of file | Markdown, a web page, data, an email, an Office document or a book, and the smallest file that still shows the problem |

Then say what you did, what you expected and what happened instead. A screenshot helps.

## Good to know

Paste only the few lines that show the problem, never a whole note. There is no private support channel, so everything is asked on the one public page. It is one person reading, and a clear question with a version and a small file is the most likely to get a reply.
